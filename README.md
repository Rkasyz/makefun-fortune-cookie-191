A one-line entry for the make.fun competition "Fortune Cookie Funnies
for Engineers": the funniest fortune cookie message for a software
engineer, 120 characters or fewer.

## The entry (116 characters)

> You will ship on Friday, break production by lunch, and fix it with a commit no one understands. Lucky numbers: 404.

116 characters, one line, inside the gate of 1–120 characters. It reads
like a real fortune — short, declarative, future-tense — and its twist
comes from the engineer's world: a Friday deploy, production broken by
lunch, fixed with a commit nobody understands, and the funniest word,
the error code 404, sitting at the very end as the "lucky number".

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` into the output directory, containing exactly
the line above, with no trailing newline.
